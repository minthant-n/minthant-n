##   What I Do

I'm a backend-focused developer working across **Java (Spring Boot)** and **TypeScript (Node.js)** ecosystems. I build REST APIs, GraphQL servers, microservices, and occasionally dabble in React frontends. Every project I push is a step in my journey to write cleaner, more scalable code.
